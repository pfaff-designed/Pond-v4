5The shell: what Pond is before it is yours. The cover, a new pond’s empty pages, the twelve premade templates, the machine surface, settings, mobile and dark. A filled-in pond is in 09 examples. Paper shell, applied across the product. The wall and the modules are the same paper, separated by shadow rather than by a frame; the rail, breadcrumb and composer are floating objects over the canvas. Ink and paper carry everything — burnt orange appears only on the one thing with a date on it, wheat only on a highlight, red only on a removal. Human content is reading type; the machine surface stays mono.

generic on purpose

Premade templates are shapes, not subjects. A recipe, a kitchen or a workout is something you make from one of these and save as your own.

one per job

Each premade template does one thing. If two would look the same when empty, one of them goes.

applied, then ordinary

Applying a template leaves plain blocks with no tie back. Editing a template changes no page made from it.

5alcommand palette — rest to open. The breadcrumb is the palette at rest. ⌘K or a click grows it in place: no modal, no scrim, the page stays as it was. This frame is live: click the breadcrumb or press ⌘K, type, ↑↓, ↵, esc.

monday — 5 oct

Shipped the rail component everywhere. Next is the breadcrumb, which needs a page-path option before it can be shared, then the composer.

0 ms — rest. glyph, path, divider, mode, ⌘K.
70 ms — the path fades out, the box widens.
140 ms — input fades in, rows start to arrive.
280 ms — open. ⌘K reads esc.
typing — pages, records, actions in one list.
spec — for whoever builds it
one objectThe breadcrumb and the palette are the same element. Opening never mounts a second surface, never adds a scrim, never moves focus away from the page except into the palette’s own input. Source: PondCommand.dc.html; written spec in design_handoff_pond/command-palette.md.
restGlass pill, 40 tall, radius 20, top 20, centred over the canvas. Width hugs content: 36 left inset, path, 10 gap, divider 1×14, 10 gap, mode toggle 22×22, 10 gap, ⌘K chip 38×22, 8 right inset. Path is the area glyph (12px) then ancestors at 68% ink, › at 80%, the current page at full ink 500. 11px, .04em.
openSame box, 560 wide, height hugs its content. Top 40px row keeps the glyph, the mode toggle and the chip exactly where they were; the path is replaced by a mono 14px input, placeholder “jump to a page, or > for actions”. Hairline, rows, key hints. The chip reads esc.
triggers⌘K / Ctrl K toggles. A click on the resting pill opens. Esc, ⌘K again, a click outside, the esc chip, or ↵ on a result closes. ↵ on a page navigates and the path updates to that page.
timingOne progress value t, 0 at rest to 1 open. Open: 280ms on ease-press cubic-bezier(.22,.8,.2,1). Close: 150ms on ease-in cubic-bezier(.4,0,1,1). Reversing mid-way starts from the current t.
mapped from te = eased t. width = lerp(rest, 560, e). height = lerp(40, open, e). path opacity = 1 − e/.35. input opacity = (e − .25)/.4. body opacity = (e − .3)/.3. row i = (e − .45 − .035i)/.4, rising 4px. key hints = (e − .6)/.4. All clamped 0–1. Radius stays 20 throughout, so the pill becomes the card without a shape change.
hover at restLifts 1px, shadow deepens to 0 24px 60px rgba(40,34,24,.18), 150ms ease-press.
reduced motionJump straight to t = 0 or 1.
