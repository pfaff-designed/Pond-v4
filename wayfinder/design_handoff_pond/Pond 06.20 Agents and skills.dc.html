1agents

An agent is a role you ask Pond to take on: a health coach, a financial advisor, an assistant. Agents live in a database in each pond, and each says what it reads and which skills it has.

yoursyou make agents. Pond itself is not one and is always there.
per pondagents, skills and tools belong to one pond.

A skill is a recipe an agent follows: when it runs, its steps, the tools it uses and what it makes. Describe it and Pond drafts it for you to accept.

a recordskills live in a skills database and can be edited like any record.
