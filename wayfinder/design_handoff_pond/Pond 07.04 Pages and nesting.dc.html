what it does

A passage on one page can start another, and the reference is kept in both directions. A section can move into a nested page, leaving a link where it was. Every page has a kind, a label you can edit, with no tie to a template.

states and rules
reference → new page6e · storyboard 05
1
select a passageSelecting text on any page raises the selection bar, the same one everywhere.
rangea reference is a page plus a range of text, so it survives edits around it.
2
the passage becomes a referenceThe selection moves into the composer as a chip. The text you type is the brief for the page.
chipsreferences sit above the text and can be removed. The passage stays highlighted while referenced.
3
add another page@ opens the same picker as anywhere else. The chosen page joins the references.
rankingpages used recently and pages linked to the existing references come first.
4
pond drafts the pageThe draft goes under the @-mentioned page and carries both references as provenance.
placementthe parent is the page you mentioned, not the source of the passage.
quoteslinked, not copied. Editing the highlight on the book updates the quote.
5
references run both waysBack on the book, the passage lists every page that quotes it.
backlinksshown under the passage, most recent first. Clicking one opens that page at the quote.
move a section into a nested page6k · storyboard 11
1
a section grows too bigThe handle on a heading selects the heading and every block under it, up to the next heading.
sectionsa heading’s handle carries its section. Any other handle carries one block.
2
a page link stays behindThe section is replaced by a page link in the same place. The rail shows the new page one level down.
in placethe link takes the exact position the blocks left.
one levelthe new page nests under the page it came from, never elsewhere.
3
the section, as its own pageThe heading becomes the title. The blocks arrive unchanged, with the parent shown above them.
/ page too/ nested page on an empty line does the same with nothing to move.
page icon and colour6y · storyboard 24
1
click a markEvery mark in the rail is a button. It opens the glyph picker under it: search, automatic, recent glyphs, then the library.
before typingautomatic, the 8 glyphs last picked in this pond, then all 182 in library order.
page marka page’s automatic mark is its kind dot. A glyph takes the dot’s place.
2
searchTyping narrows to glyphs whose name contains the text; numbered shapes match by number.
keysarrows move, ↵ picks, esc closes.
directa pick applies at once and closes, with undo. No diff.
3
area colourAn area adds a colour row: ink, sage, mist or navy, each drawn as the area’s glyph in that colour.
marks onlythe area’s glyph and the marks of pages inside it. Never text, rows or grounds.
inheritsa page always takes its area’s colour. It has no colour of its own.
yoursthe person assigns area colours; Pond never does.
4
back to automaticAutomatic is the first row: the kind dot for a page, the title-derived glyph for an area. Ink puts an area’s colour back.
undoeach pick is one change, one undo.
5
phone and inkOn a phone the picker is a sheet with 44px targets. In ink, navy draws as mist.
