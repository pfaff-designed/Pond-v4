what it does

A template is a stack of blocks with labels and placeholders. Templates lead the / menu while a page is empty, Pond can propose one as a diff when asked, and any page can be saved as your own. A page keeps no tie to the template it came from.

states and rules
blank page → recipe6f · storyboard 06
1
a blank nested page＋ in recipes makes an empty page under it. The body is one empty line with a hint.
one hintthe empty page shows a single line of help. No template gallery takes over the screen.
recordrecipes reads the recipes database, so a page made under it is a record there and gets its fields. under an ordinary page it is just a page.
2
/ on an empty pageOn an empty page the menu leads with templates. The one the sibling pages use is first.
empty onlytemplates apply in place only while the page is empty.
rankedtemplates used by sibling pages rank first; yours sit next to premade.
3
preview the stackMoving onto a template draws its blocks on the page as flat outlines, named in mono.
no commitpreview writes nothing. Esc returns to the empty page.
4
appliedThe blocks land with labels and placeholders. The cursor goes to the title.
plain pageafter applying there is no link to the template. The page is ordinary blocks.
databasesa template has no database of its own. Its blocks are linked to a database on the page, like any block.
undo⌘Z empties the page again.

1
notes, not a recipeA page written freehand. Its siblings all use the recipe template (yours); this one never did.
askedthe user asks in the composer. Pond does not restructure pages unprompted.

acceptedThe page now matches its siblings. The meta line says recipe.
same as manualthe result is identical to applying the template by hand and filling it in.
