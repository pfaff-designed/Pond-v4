what it does

Agents are roles you make; Pond itself is not one. Skills are recipes an agent follows, and tools are what Pond and agents may use. Every agent works like Pond: you ask, it proposes a diff, you accept. Skills run when asked, from / or ⌘K, on a schedule, or when something happens.

states and rules
make an agent and a skill by asking, run them four ways, see what they propose, and choose what they may use6t · storyboard 20
1
agentsAn agent is a role you ask Pond to take on: a health coach, a financial advisor, an assistant. Agents live in a database in each pond, and each says what it reads and which skills it has.
yoursyou make agents. Pond itself is not one and is always there.
per pondagents, skills and tools belong to one pond.
2
make an agent by askingTell Pond what you want and it drafts the agent: name, role, what it reads and its tools. You accept, ask for changes, or discard it.
a draftnothing exists until you accept.
one patternevery agent works like Pond: you ask, it proposes a diff, you accept, the change is made.
3
an agent’s pageEach agent opens like a record: its role in prose, its skills and when they run, its tools, and what it reads. Everything can be edited by hand or by asking.
no direct editsan agent never changes a page by itself.
4
write a skill by askingA skill is a recipe an agent follows: when it runs, its steps, the tools it uses and what it makes. Describe it and Pond drafts it for you to accept.
a recordskills live in a skills database and can be edited like any record.
5
ask an agentWrite @ and an agent’s name in the composer, or / for a skill. The answer says which agent answered, which skill and tools it used, and what it read.
namedwhoever did something is always named: pond, an agent, or a person.
6
what an agent didA scheduled run lands in the change log under the agent’s name, as a proposed diff. Nothing changes until you accept it.
same buttonsaccept, request changes, reject, as for Pond and people.
7
when skills runFour ways: asked in the composer, from / or ⌘K, on a schedule, or when something happens in the pond, such as a capture, a new record or a date.
visibleevery skill shows its trigger. Nothing runs that isn’t listed.
8
toolsTools are what Pond and agents can use: actions on the pond and connections outside it. Each pond has its own list, and an agent can only use tools that are on here.
bothreading, searching and proposing, plus web, email, sheets and handwriting. Nothing edits directly.
deep researchis a mode of asking, specified in 7a. An agent with the web tool reads the web the same way.
9
mobileAgents, skills and @-asking all work on the phone.
same as desktopmaking and running agents is not desktop-only.
