what it does

Drop an HTML file in the composer and Pond rebuilds it as a Pond page. Pond reads the file, asks what the page is for, which data you’ll keep adding to and what to leave out, then proposes a layout as one diff. Once you accept, the page is built from Pond’s own blocks and records. The file stays on the page, and each block links back to the part it came from.
